# ステージング(Git)

[git] で 追加/更新/削除 を行ったファイルの内、[コミット(Git)]したい内容を登録する場所。
ファイル単位の他に[ハンク(Git)]という単位で ステージング に登録することも出来ます。

## ユースケース
1. 作業A と 作業B を同時進行で行う。
1. 作業B が完了したので、コミットしたい。
1. 作業A は完了してないので、コミットしたくない。
1. 作業A で編集したファイルだけ、にステージングに追加する。
1. コミットすると、作業A で編集したファイルだけ[リポジトリ(Git)]に登録されて、履歴に残る。

## ステージングに追加するコマンド
### ファイル名を指定して追加
``` bash
git add <filename>
```
``` bash
git add *.html
```
↑ ワイルドカードも指定できます
### 「変更/追加/削除」したファイル全てを追加
``` bash
git add -A
```
### 「変更/削除」したファイル全てを追加
``` bash
git add -u
```
### 変更されたファイルをインタラクティブに追加
``` bash
git add -i
```
### 実際には追加せずに、追加するファイル名を一覧表示する
``` bash
git add -n
```
### `.gitignore` で設定したファイルも強制的(force)に追加
``` bash
git add -f
```
### ハンク(hunk)単位でステージングに追加
``` bash
git add -p
```
